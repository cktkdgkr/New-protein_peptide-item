# Exclusion Criteria — 제외 기준

## 1. 핵심 원칙
**임상시험(Clinical Trial)을 거쳐야 하는 therapeutic API 그 자체는 제외한다.**
즉, "그 단백질·펩타이드 자체"가 인체 투여용 신약 후보로서 IND·1상·2상·3상을 통과해야 시장 진입이 가능한 아이템은 후보화하지 않는다.

## 2. 명시적 제외 예시
- 신규 항체 의약(mAb, bispecific, ADC payload 단백질 등) 자체
- 신규 효소대체요법(ERT) 효소 자체 (예: 새 lysosomal enzyme as drug)
- 신규 호르몬·사이토카인 의약 단백질 자체
- 신규 백신 항원 단백질 자체
- 신규 펩타이드 의약(예: 새 GLP-1, 새 항균 펩타이드 약) 자체
- 세포·유전자 치료제로서의 단백질 (CAR, gene editor를 환자에 직접 투여하는 형태)

## 3. 포함되는 인접 경우 (혼동 주의)
다음은 위 제외 원칙의 예외이며 **포함**된다:
- 위 약들의 **생산 공정**에 쓰이는 효소 (예: ADC 만들 때 conjugation enzyme — 그 효소 자체는 임상 신약이 아니다).
- 위 약들의 **제형 변경**에 쓰이는 효소 (예: 단클론항체를 IV→SC로 바꿔주는 hyaluronidase — 이미 의약품으로 승인된 부형제급 단백질이거나, 새 변이체라도 결합제형으로 별도 임상 부담이 상대적으로 낮은 경우. 단 차세대 hyaluronidase 자체의 임상 부담은 사례별 판단).
- **체외 진단**용 효소 (인체 투여가 아니므로 임상 부담 없음 또는 진단 인허가 트랙).
- **연구용·산업용** 효소.

## 4. 경계 사례 판정 규칙
- "단백질 X가 SC 전환 조력 효소인데 자체로도 신약 후보"인 경우 → **공정/제형 용도 시나리오만 사업화 후보화**하고, 신약 시나리오는 후보 카드에서 명시적으로 out-of-scope 처리.
- "체외 진단으로 출발했으나 인체 투여 시 신약 임상이 필요한 효소" → 진단 용도만 포함, 치료 용도는 제외.
- 판정이 모호하면 후보 카드의 "scope_judgement" 항목에 근거를 남기고 보수적으로 제외 처리한다.

## 5. 기타 제외
- 공개된 정보가 거의 없어 검증이 사실상 불가능한 아이템(검색 결과 0~1건 수준)은 본 라운드에서 제외하고 다음 회차의 "탐색 후보"로 별도 표기.
- 명백히 윤리·규제 금지(BSL-4 병원체 단독 사용 효소 등) 아이템은 제외.
